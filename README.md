# Student Attendance Management System

A responsive mini project built with HTML, CSS and JavaScript.

## Demo login
- Username: `admin`
- Password: `admin123`

## How to run in VS Code on Mac
1. Extract/open this project folder in VS Code.
2. Open `index.html`.
3. Recommended: install the **Live Server** extension in VS Code.
4. Right-click `index.html` → **Open with Live Server**.
5. Login with the demo credentials.

No Node.js, Python or database is required for this version. Data is stored in the browser using LocalStorage.

## Main modules
- Admin login
- Dashboard
- Student management
- Add/delete/search students
- Date-wise attendance marking
- Mark all present/absent
- Attendance validation before saving
- Attendance records
- Student-wise attendance percentage
- CSV report export
- Responsive layout
